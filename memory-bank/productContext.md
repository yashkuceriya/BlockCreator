# Product Context

## Why This Exists
Automattic hiring challenge. Build an AI-powered WordPress Block Theme Generator.
The PDF evaluation criteria:
- Must have: valid theme gen, zero wp:html, AI integration, validation, tests, clean code, docs
- Raises the bar: visually high-quality themes, thoughtful prompts, genuine ADR, What I'd Do Next

## Key Differentiators (vs other submissions)
1. **Demo mode** — reviewer clicks "Try Demo", sees full experience without API key
2. **Theme iteration** — "make it warmer" refinement loop, not just one-shot generation
3. **Live WordPress Playground** preview, not mockups
4. **98 tests** with security hardening tests
5. **Hand-crafted demo theme** (Aurora Studio) proves output quality
6. **11 ADR decisions** with trade-offs
7. **Product Strategy** with personas, flows, risks, roadmap
